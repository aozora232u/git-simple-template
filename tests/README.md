# テスト

`scripts/` の動きを確かめる自動テストです。追加のインストールは要りません。Git Bash だけで動きます。

## 実行方法

リポジトリの直下で、Git Bash から実行します。

```
bash tests/run.sh
```

すべて実行すると数分かかります。最後に各テストの `PASS` / `FAIL` が出ます。

1 つだけ実行するときは、テストの関数名を渡します(複数も可)。

```
bash tests/run.sh test_start_creates_branch
```

テスト名の一覧は `grep -h '^test_' tests/test_*.sh` で見られます。

## 補足

- テストは一時フォルダに、GitHub の代わりのリポジトリを作って動かします。あなたのリポジトリや GitHub には何も送りません
- メンバーは触らなくてかまいません。テンプレートを更新する作成者のためのものです
