# 更新履歴

テンプレートの更新履歴です。版ごとに、何が直ったか、取り込むべきか、手作業が必要かを書きます。取り込み方は [leader-guide.md](leader-guide.md) の 3 章にあります。

## v2.0.0 (2026-10-23)

- 「作業開始」は新しいブランチを作るだけになった。同じ名前が既にあれば「既にあります」と止まる
- 自分の作業の続きは「ブランチ切り替え」で行う。一覧で自分のブランチに「← あなたのブランチ」と付く
- 他の人のブランチは閲覧用(`view/...`)で開く。記録も送信もされず、離れるときに確認のうえ捨てられる
- 「提出」は、送る前に main の変更を取り込む。衝突したら提出を中止し、PR.md も書いた内容に戻す
- 「やり直し」は、記録していない変更を `local/backup/` のフォルダではなく差分(`git stash`)として控える。エクスプローラーは開かなくなった
- 新しいメニュー「控えを戻す」を追加(メニューは 5 つ)。控えを今の自分のブランチに当て直す
- マージ済みで GitHub から消えたブランチは、今いないものも含めてまとめて `merged/...` に退避する
- ログのメニュー名に `restore`(控えを戻す)を追加
- 取り込み方は通常の更新手順(leader-guide.md の 3 章)どおり
